วิธีเปลี่ยนเอกสาร

1. ใส่ไฟล์ PDF ใหม่ลงในโฟลเดอร์นี้ ชื่อไฟล์เป็นอะไรก็ได้
2. เปิดเทอร์มินัลที่โฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง npm run web-menu
   คำสั่งนี้สร้างรูป WebP ทีละหน้าไว้ในโฟลเดอร์ pages และสร้างไฟล์ OnTheHillMenu-web.pdf สำหรับปุ่ม Open PDF
3. รีเฟรชหน้าเว็บ เว็บจะโหลดเฉพาะหน้านั้น ไม่ต้องรอทั้งเล่ม
4. ถ้าจะให้เมนูบนอินเทอร์เน็ตเปลี่ยนตาม ให้ส่งโฟลเดอร์ pages และไฟล์ -web.pdf ขึ้น GitHub

ไฟล์ต้นฉบับที่ใหญ่เกิน 80 MB ยังเก็บไว้ในโฟลเดอร์นี้ได้ เว็บจะไม่ใช้อัปโหลดไฟล์นั้น

เล่มอื่นอยู่คนละโฟลเดอร์ เรียงจากบนลงล่างคือ เมนูหลัก, overview, last-minutes
แต่ละเล่มมีไฟล์ PDF สำหรับปุ่ม Open PDF และโฟลเดอร์ pages เป็นรูป WebP
