วิธีเปลี่ยนเอกสาร

1. ใส่ไฟล์ PDF ใหม่ลงในโฟลเดอร์นี้ ชื่อไฟล์เป็นอะไรก็ได้
2. ลบไฟล์ PDF เก่าออก ไฟล์ OnTheHillMenu-web.pdf จะถูกสร้างใหม่ได้
3. ถ้าไฟล์ใหญ่กว่า 80 MB ให้เปิดเทอร์มินัลที่โฟลเดอร์โปรเจกต์ แล้วรัน npm run web-menu
4. รีเฟรชหน้าเว็บ

เว็บจะใช้ไฟล์ที่เล็กพอจะอัปโหลดได้ ถ้ามีไฟล์ -web.pdf ระบบจะไม่ใช้ไฟล์ต้นฉบับที่ใหญ่เกิน 80 MB
ไฟล์ต้นฉบับยังเก็บไว้ในโฟลเดอร์นี้ได้
ถ้าจะให้เมนูบนอินเทอร์เน็ตเปลี่ยนตาม ให้อัปไฟล์ -web.pdf ขึ้น GitHub แล้ว Vercel จะเผยแพร่ให้ใหม่
